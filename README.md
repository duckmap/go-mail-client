# gomail — консольный почтовый клиент на Go

Полнофункциональный TUI-клиент электронной почты (IMAP + SMTP) для терминала.
Трёхпанельный интерфейс: **слева — ящики и папки, в центре — список писем,
справа — просмотр письма**. Учётные записи настраиваются прямо в интерфейсе.

```
 ✳ gomail  ›  ivan@company.ru                                                  ⏺ в сети
────────────────────────────────────────────────────────────────────────────────────────
 Ящики            │ ▌ Входящие                  5 · 2 нов. │ Письмо · 2 влож.
 ▾ ● Рабочий      │ ❯●★   Анна Смирнова Отчёт за Q3…     3ч│ ⏺ Анна Смирнова
   ❯ Входящие     │    ↩  Сергей Волков Re: Встреча…     1д│ │ Кому  Иван Петров
     Отправленные │       GitHub        [gomail] PR…     2д│ │ Дата  25.09 10:15
     Черновики    │       Олег Кузнецов Счёт №418…       3д│ ⎿ Тема  Отчёт за Q3
     Корзина      │                                        │
 ▸ ✗ Личный       │                                        │ ──────────────────────────
                  │                                        │
                  │                                        │ Иван, добрый день!
                  │                                        │
                  │                                        │ Во вложении финальная
                  │                                        │ версия отчёта за Q3.
                  │                                        │
                  │                                        │ Прошу посмотреть раздел 2:
                  │                                        │ там расхождения с драфтом.
                  │                                        │
────────────────────────────────────────────────────────────────────────────────────────
 ❯ ↑↓ письмо · ↵ просмотр · c написать · r ответить · ? помощь
 ivan@company.ru · Входящие · 12 писем · 2 новых                             ⏺ готово
```

Оформление — в духе терминальных агентов (Claude Code, Codex CLI): без рамок,
тонкие разделители колонок, один тёплый акцент, строка-приглашение `❯` внизу и
маркеры `⏺` / `⎿` в шапке и просмотре письма. Цвета адаптируются под светлую и
тёмную тему терминала.

Скриншоты всех экранов (реальная отрисовка приложения): **`demo/index.html`**.

## Возможности

- **Несколько учётных записей** IMAP/SMTP, подключение при запуске, автопереподключение;
- **Настройка ящиков прямо в интерфейсе** (клавиша `a`): форма со всеми параметрами,
  проверка соединения (`t`), сохранение в файл (`ctrl+s`);
- TLS / STARTTLS / без шифрования, опция «не проверять сертификат» для self-signed;
- **Папки**: дерево с вложенностью, автоопределение специальных папок
  (Входящие, Отправленные, Черновики, Корзина, Спам, Архив — по RFC 6154 и по именам,
  включая русские), создание новых папок (`N`);
- **Список писем**: флаги (● непрочитанное, ★ важное, ↩ отвеченное, ✎ черновик),
  компактные даты («35м», «13:45», «вчера», «26 окт»),
  счётчик непрочитанных, загрузка последних N писем (настраивается);
- **Просмотр письма**: заголовки, текст, HTML-письма конвертируются в читаемый текст,
  вложения показываются списком и сохраняются на диск (`S`);
- **Написание писем**: Кому/Копия/Тема/вложения-файлы, выбор ящика-отправителя,
  отправка через SMTP с автоматическим сохранением копии в «Отправленные»;
- **Ответ / Ответ всем / Пересылка** — с цитированием, правильными `In-Reply-To`/
  `References` и вложениями исходного письма;
- **Черновики**: сохранение в папку Drafts (`ctrl+d` в письме);
- **Операции с письмами**: удалить в корзину (`d`), удалить безвозвратно (`D`),
  переместить (`m`), скопировать (`y`), в спам/из спама (`J`),
  прочитано/непрочитано (`u`), важное (`*`), прочитать все (`A`);
- **Поиск** по текущей папке — IMAP SEARCH по тексту и заголовкам (`/`);
- **Автообновление** (по умолчанию каждые 2 мин) и ручное (`ctrl+r`/`F5`);
- Мышь: выбор папок и писем, прокрутка колеса;
- **Интерфейс в стиле терминальных агентов**: без рамок, один акцентный цвет,
  строка-приглашение `❯`, маркеры `⏺`/`⎿`, спиннер `·✢✳✶✻✽`;
- Кодировки: UTF-8, KOI8-R, windows-1251 и др. (через `go-message` + `x/text`);
- **Демо-режим** `./gomail -demo` — встроенные IMAP/SMTP-серверы с примерами писем,
  чтобы попробовать интерфейс без реального ящика.

## Сборка и запуск

Нужен Go 1.21+ (разрабатывалось на 1.27):

```sh
make            # или: go build -o gomail .
./gomail        # обычный запуск
./gomail -demo  # демо-режим (локальные серверы, логин не нужен)
./gomail -config /путь/к/config.json
```

При первом запуске нажмите `a` и добавьте учётную запись.

## Настройка ящиков

### Через интерфейс (рекомендуется)

1. `a` — экран «Настройка почтовых ящиков»;
2. `n` — новая запись, заполните поля (перемещение — `tab`/стрелки,
   значения «шифрование» и «не проверять сертификат» — `←`/`→`);
3. `t` — проверить соединение (IMAP и SMTP);
4. `ctrl+s` — сохранить и подключить.

### Параметры популярных провайдеров

| Провайдер | IMAP | SMTP | Примечание |
|---|---|---|---|
| Mail.ru | imap.mail.ru:993 TLS | smtp.mail.ru:465 TLS | включите IMAP в настройках ящика |
| Yandex | imap.yandex.ru:993 TLS | smtp.yandex.ru:465 TLS | нужен «пароль приложений» |
| Gmail | imap.gmail.com:993 TLS | smtp.gmail.com:465 TLS | нужен App Password (2FA) |
| Собственный | хост:143 STARTTLS | хост:587 STARTTLS | или 993/465 TLS |

Логин обычно равен e-mail; если оставить пустым — подставится e-mail.

### Файл конфигурации

Хранится в `~/.config/gomail/config.json` (или `$XDG_CONFIG_HOME`, или `-config`,
или `$GOMAIL_CONFIG`), права `0600`. Пример:

```json
{
  "version": 1,
  "accounts": [
    {
      "id": "a1b2c3", "name": "Рабочий",
      "email": "ivan@company.ru", "sender_name": "Иван Петров",
      "imap_host": "imap.company.ru", "imap_port": 993, "imap_tls": "tls",
      "imap_user": "ivan", "imap_pass": "секрет",
      "smtp_host": "smtp.company.ru", "smtp_port": 465, "smtp_tls": "tls",
      "smtp_user": "ivan", "smtp_pass": "секрет",
      "sent_folder": "", "trash_folder": "", "drafts_folder": "", "junk_folder": ""
    }
  ],
  "attachment_dir": "~/Downloads",
  "refresh_sec": 120,
  "fetch_limit": 300
}
```

- `imap_tls`/`smtp_tls`: `"tls"` (скрытое, порты 993/465), `"starttls"`, `"none"`;
- `imap_insecure`/`smtp_insecure`: `true` — не проверять сертификат сервера;
- `*_folder` — переопределение специальных папок (обычно определяются автоматически);
- `attachment_dir` — куда сохраняются вложения (клавиша `S`);
- `refresh_sec` — период автообновления (0 — выключить);
- `fetch_limit` — сколько последних писем загружать в папке.

> ⚠️ Пароли хранятся в файле конфигурации в открытом виде (файл защищён правами
> 0600). Для повышенной безопасности можно выдать приложению «пароль приложения».

## Горячие клавиши

### Основной экран

| Клавиша | Действие |
|---|---|
| `tab`, `←`/`→` | переключение панелей |
| `↑`/`↓`, `j`/`k` | навигация по списку |
| `g` / `G`, `PgUp`/`PgDn` | в начало/конец, страница |
| `enter` | открыть папку / перейти к просмотру |
| `c` | написать письмо |
| `r` / `R` / `f` | ответить / ответить всем / переслать |
| `d` / `D` | удалить в корзину / безвозвратно |
| `m` / `y` | переместить / скопировать в папку… |
| `J` | в спам (из спама — во входящие) |
| `u` / `*` / `A` | непрочитано↔прочитано / ★ важное / прочитать все |
| `S` | сохранить вложения текущего письма |
| `/` | поиск в папке, `esc` — сброс результатов |
| `N` | новая папка (в панели папок) |
| `ctrl+r`, `F5` | обновить |
| `a` | настройка учётных записей |
| `?` | справка, `q` — выход |

### Письмо

`ctrl+s` отправить · `ctrl+d` в черновики · `tab`/`↑↓` поле · `←`/`→` смена
ящика-отправителя · `esc` отмена (с подтверждением).

### Учётные записи

`↑↓` выбор · `enter` правка · `n` новая · `ctrl+d` удалить · `t` проверка
соединения · `ctrl+s` сохранить · `esc` назад.

## Технологии

- [bubbletea](https://github.com/charmbracelet/bubbletea) + bubbles + lipgloss — TUI;
- [go-imap](https://github.com/emersion/go-imap) — IMAP-клиент;
- [go-smtp](https://github.com/emersion/go-smtp) — SMTP-клиент;
- [go-message](https://github.com/emersion/go-message) — MIME, кодировки, RFC 2047;
- [x/net/html](https://golang.org/x/net/html) — разбор HTML.

## Известные ограничения

- Нет IMAP IDLE — входящие подтягиваются автообновлением (`refresh_sec`) или `ctrl+r`;
- Черновики сохраняются, но не открываются для дальнейшего редактирования;
- HTML-письма показываются текстом (без картинок и ссылок-кнопок — ссылки выводятся как `текст [url]`);
- Пароли хранятся в конфигурационном файле (0600), а не в системной связке ключей.
